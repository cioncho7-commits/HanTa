# HanTa (한타)

한글 낱말을 타이핑해서 클리어하는 테트리스 스타일 타이핑 게임입니다.

## 게임 규칙

- 시작 화면에서 이메일 회원가입/로그인 또는 Google · 카카오 · 네이버 계정(데모용 모의 로그인)으로 입장합니다.
- 플레이 화면 상단 5% 영역에 내 스코어/최고 스코어(최고 기록 보유자의 닉네임-키보드이름 포함)와 닉네임(키보드이름)이 표시됩니다.
- 도형은 1~5칸 폴리오미노(테트리스 블록)이며, 칸마다 한 글자씩 실제 의미가 있는 한글 단어(총 500개, 음절 수별 100개씩)가 적혀 있습니다.
- 도형은 3초에 한 칸(14px)씩 자동으로 내려옵니다. 하단 입력창에 도형에 적힌 단어를 정확히 입력하면 글자가 지워지며 그때부터 도형을 조작할 수 있습니다.
  - **Space**: 90도 회전
  - **Backspace**: 즉시 수직 낙하(하드 드롭)
  - **드래그(터치)**: 좌우 이동
- 한 행이 가로로 가득 차면 그 줄이 사라지고, 사라진 블록 수만큼 점수가 올라갑니다.
- 20초마다 바닥에서 한 행(14px)이 올라오며 압박이 심해집니다.
- 새 도형이 스폰될 자리가 막히면 게임 오버입니다.
- 스테이지: 초급(1~2글자), 중급(1~4글자), 고급(1~5글자).

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드
npm run lint      # oxlint
```

## 참고

- 소셜 로그인(Google/카카오/네이버)은 실제 OAuth 자격 증명이 없는 데모 환경이라, 클릭 시 닉네임과 키보드 앱 이름을 입력받아 로그인을 시뮬레이션합니다. 실제 서비스에 배포하려면 각 제공자의 OAuth 클라이언트 연동이 필요합니다.
- 인증 정보와 최고 점수는 브라우저 `localStorage`에 저장됩니다(백엔드 없음).
