# HanTa (한타)

한글 낱말을 타이핑해서 클리어하는 테트리스 스타일 타이핑 게임입니다.

## 게임 규칙

- 시작 화면(데모용, 별도 로그인/회원가입 없음)에서 1행 닉네임, 2행 키보드어플이름, 3행 초급/중급/고급 스테이지 박스를 입력·선택하면 바로 플레이 화면으로 이동합니다.
- 플레이 화면 상단 5% 영역에 내 스코어/최고 스코어(최고 기록 보유자의 닉네임-키보드이름 포함)와 닉네임(키보드이름)이 표시됩니다.
- 도형은 1~5칸 폴리오미노(테트리스 블록)이며, 칸마다 한 글자씩 실제 의미가 있는 한글 단어(총 500개, 음절 수별 100개씩)가 적혀 있습니다.
- 도형은 3초에 한 칸(14px)씩 자동으로 내려옵니다. 하단 입력창에 도형에 적힌 단어를 정확히 입력하면 글자가 지워지며 그때부터 도형을 조작할 수 있습니다.
  - **Space**: 90도 회전
  - **Backspace**: 즉시 수직 낙하(하드 드롭)
  - **드래그(터치)**: 좌우 이동
- 한 행이 가로로 가득 차면 그 줄이 사라지고, 사라진 블록 수만큼 점수가 올라갑니다.
- 20초마다 바닥에서 한 행(14px)이 올라오며 압박이 심해집니다.
- 새 도형이 스폰될 자리가 막히면 게임 오버입니다.
- 스테이지: 초급(1~2글자), 중급(1~4글자), 고급(1~5글자).

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드
npm run lint      # oxlint
```

## Android Studio에서 열기

이 저장소는 웹 앱(Vite + React)이라 루트 폴더 자체는 Android Studio가 인식하지 못합니다. 대신 [Capacitor](https://capacitorjs.com/)로 만든 `android/` 폴더(네이티브 Gradle 프로젝트)를 열어야 합니다.

```bash
npm run android:sync   # 웹 빌드 후 android/ 프로젝트에 반영
npm run android:open   # Android Studio로 android/ 폴더 열기 (Studio 설치 필요)
```

또는 Android Studio에서 `Open` → 이 저장소의 `android` 폴더를 직접 선택해도 됩니다. 웹 코드(`src/`)를 수정한 뒤에는 반드시 `npm run android:sync`를 다시 실행해 변경사항을 네이티브 프로젝트에 반영해야 합니다.

## 참고

- 현재는 로그인/회원가입 없이 닉네임과 키보드 앱 이름만 입력하면 바로 플레이할 수 있는 데모 버전입니다.
- 최고 점수는 브라우저 `localStorage`에 저장됩니다(백엔드 없음).
